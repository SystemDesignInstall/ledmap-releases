# LedMAP releases

Public, binary-only distribution for LedMAP Windows stable releases.

Source code is maintained separately in a private repository. Only signed, verified release artifacts should be published here.

Each stable GitHub release contains the Windows x64 NSIS installer, portable executable, `latest.yml`, blockmap and `SHA256SUMS.txt`. LedMAP uses these published releases for checking updates.

Do not upload unsigned CI builds to this repository.
